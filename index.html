A NOTE ABOUT THIS PROJECT

Small, useful, and intentionally simple.

LinkLite is a front-end demonstration project. It validates URLs and stores demo link records in your browser. Real public short links and server-side redirects require a backend service; demo links work only in this browser while their saved records remain available.
